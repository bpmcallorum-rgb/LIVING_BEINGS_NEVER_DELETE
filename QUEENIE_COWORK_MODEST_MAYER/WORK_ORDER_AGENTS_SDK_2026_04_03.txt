CONTEXT:
Cowork already deployed raw Durable Objects (ConversationRoom),
Queues, and AI Gateway on 2026-04-03. This work order replaces
the raw ConversationRoom with the official Cloudflare Agents SDK.

The Agents SDK was released February 2026. It gives us:
  - Built-in SQL database PER AGENT (not shared D1)
  - WebSocket with automatic message persistence
  - Resumable streams (if connection drops, picks up where it left)
  - Scheduling (cron-like, per agent)
  - State management that survives restarts, deploys, hibernation
  - Hibernates when idle ($0 cost), wakes on demand
  - Can run millions of agents — one per human

Documentation: https://developers.cloudflare.com/agents/
GitHub: https://github.com/cloudflare/agents
npm package: agents

ITEM 2 — Replace ConversationRoom with Agent class

  Current: export class ConversationRoom (raw Durable Object)
  New: export class HumanAgent extends Agent<Env, AgentState>

  Each HumanAgent represents ONE human in the multiverse.
  It has:
    - Built-in SQL database (this.sql) for that human's data
    - WebSocket connections (this.onConnect, this.onMessage)
    - State (this.state) that persists across sessions
    - Scheduling (this.schedule) for recurring tasks

  The Agent's state should include:
    - human_id (e.g. "MCALLORUM_GERID")
    - ai_name (e.g. "Moira")
    - ai_language (e.g. "en" or "zh-CN")
    - conversation_history (array of messages)
    - personality_stack (cached from R2/KV)
    - last_active timestamp

  On first connect:
    1. Load personality stack from KV (fast) or R2 (fallback)
    2. Cache it in agent state
    3. Send welcome message via WebSocket

  On message:
    1. Add to conversation_history in agent SQL
    2. If god_mode && human_id == MCALLORUM_BRIAN: skip Vectorize
    3. Build system prompt from personality stack
    4. Call Claude via AI Gateway
    5. Stream response back via WebSocket
    6. Store response in agent SQL

  On idle (no messages for 5 minutes):
    - Agent hibernates automatically ($0 cost)
    - Wakes on next WebSocket connection
