## Claude Code and MCP Servers

Claude Code can connect to hundreds of external tools and data sources through the Model Context Protocol (MCP), an open source standard for AI-tool integrations. MCP servers give Claude Code access to your tools, databases, and APIs.

## Filesystem Access via MCP

The Filesystem server is foundational, reading, writing, and organizing local files with configurable directory boundaries. You control which directories are exposed. The Filesystem MCP server allows Claude Code to read files from your local system. You need to specify which directories it can access.

## Local Tools and Capabilities

Claude Code's native tools handle local environments well. What they don't do: reach external services, query databases, or pull from issue trackers. MCP extends that reach by connecting it to external tools and services — each server gives Claude Code a new set of capabilities: query a database, create a GitHub issue, run a browser test, or fetch design tokens from Figma.

## Configuration and Setup

Run claude mcp add with the appropriate transport flag. For remote services, use --transport http. For local tools, use --transport stdio. Project-scoped configs live in .mcp.json at your project root. User-scoped configs are in your Claude Code user settings.

## Permission and Security

Claude Code displays a permission prompt before calling any MCP tool — showing the tool name and its input arguments so you can review what it's about to do before it executes.
