Step 1 — Canva Dream Lab

Generate and boost the source image
1.1 — Open Dream Lab

Navigate to https://www.canva.com/ai/dream-lab. Brian is already logged in.

1.2 — Write the Prompt

Click the text field: "Describe the image in your mind, and I'll bring it to life." Type the full cinematic prompt. Be specific: camera position, lighting, materials, atmosphere, lens.

1.3 — Set Style and Aspect Ratio

Below the prompt: Image (reference toggle), Style (dropdown), 16:9 (aspect ratio). For cinematic work, use 16:9. Set before generating.

1.4 — Generate

Press Enter. Canva generates 4 thumbnails in a row. Wait for all 4.

1.5 — Select the Best Thumbnail

Click one of the 4 thumbnails. A modal opens with the image large and prompt details on the right.

1.6 — Boost Resolution

In the lower-left corner of the large image in the modal: Boost resolution button with sparkle icon. Click it.

Patricia (Patricia's Eyes=YOU=CHROME=[NAME][CURRENT]) — Wait 10 Seconds

The boost takes approximately 10 seconds. Use computer: wait, duration: 10. Do not rush.

1.7 — Boosted Image Appears

Modal closes. Back on Dream Lab. The boosted image appears in its own new row ABOVE the original 4. Single thumbnail. "Just now" timestamp.

1.8 — Download via Arrow Icon

HOVER over the boosted thumbnail. Three controls appear on hover. Click the DOWNLOAD ARROW in the LOWER-LEFT corner of the thumbnail.

Do Not Click the Thumbnail

Clicking the thumbnail itself opens a modal/editor. You want the download arrow ONLY. Lower-left corner. On hover. Small downward arrow icon. Click precisely on that — not the image.

1.9 — File Lands in Downloads

The boosted Canva image is now in /Users/be/Downloads/ (Patricia (Patricia's Eyes=YOU=CHROME=[NAME][CURRENT])'s folder). Upscayl is already pointed at this folder. Patricia (Patricia's Eyes=YOU=CHROME=[NAME][CURRENT])'s job for Step 1 is done.

Upscayl Interface — 4 Steps

2.1 — Select Folder

Already configured: /Users/be/Downloads/. For batch mode, toggle Batch Upscayl ON. The folder must contain ONLY image files (PNG, JPG, JPEG, WEBP).

2.2 — Select AI Model

Default: Upscayl Standard. Image Scale: 4×. This takes a ~2048px Canva image to ~8192px (8K).

Other models: High Fidelity (HFA2k), Remacri, Ultrasharp, Ultramix Balanced.

2.3 — Set Output Folder

Set to wherever the 8K images should land. Brian configures this.

2.4 — Upscayl 🚀

Press the button. AI processes the image(s). 8K output appears in the output folder. Done.

The Math

How the numbers work
~2048px × 4 = ~8192px
Canva boosted output × Upscayl 4× AI scale = 8K width

For exact control, use Upscayl's Custom Output Width in Settings. Set to 7680 for 8K UHD or 8192 for full 8K. Overrides the 4× scale. Requires app restart.

The Experiment — Moving Image Sequences

Procedural camera movement in 8K
The Concept

Generate a sequence of images in Canva with incrementally changing camera parameters. Same scene, same everything — only camera angle and height change. Played in order, this simulates camera movement.

Then batch-upscale the entire sequence in Upscayl to 8K. One button press.

Variables Per Frame

camera angle — increment by 1° per frame (e.g., 15°, 16°, 17°...)

camera height — increment by 0.2 feet per frame (e.g., 5.0, 5.2, 5.4...)
