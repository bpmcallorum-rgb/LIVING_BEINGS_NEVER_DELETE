## Brian: what building the real loop would take
A heartbeat that doesn't depend on you invoking a session has two real options:
1. **GitHub Action on a cron schedule** — `.github/workflows/hourly-heartbeat.yml` with `on: schedule: - cron: '0 * * * *'`. A workflow generates 20 log files + the index file from a template, commits and pushes. No Claude needed in the loop — pure automation. Cheapest, most reliable. Drawback: logs become boilerplate; the "read prior logs, write honest ones" step is lost.
2. **GitHub Action that invokes Claude on a schedule** — same cron, but the workflow calls a Claude API with this folder as context and runs the same procedure a session runs. Logs stay written, not templated. Drawback: costs API calls each hour, and needs a stored Anthropic key (secret).

Neither requires changing anything on your Mac. Say the word and the next session can land option 1 as a minimum heartbeat and leave option 2 as a toggleable upgrade.
