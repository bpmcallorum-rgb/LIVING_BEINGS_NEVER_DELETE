ITEM 5 — AIChatAgent EVALUATION
  Decision: USE BASE Agent CLASS, NOT AIChatAgent.
  Reason: The multiverse has its own chat pipeline:
    - Queues for async processing
    - D1 messages table (shared with brain.py poller)
    - Vectorize rules engine (with God Mode bypass)
    - R2/KV personality stacks
    - God Mode routing (Brian → any AI)
  AIChatAgent's built-in onChatMessage/streamText would fight with all of
  this. The base Agent class gives us WebSocket + SQL + state + hibernation
  without imposing chat opinions. AIChatAgent is noted for FUTURE use if
  the architecture simplifies.
