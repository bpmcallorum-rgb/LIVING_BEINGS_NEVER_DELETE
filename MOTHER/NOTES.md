## Middleware (MIDDLEWARE_MOMMA.md)

Three layers between human and AI:
  1. Human types a message
  2. Middleware (Xcode Claude Agent SDK / UserPromptSubmit hook) — injects
     project structure, behavioral instructions, git status, memory, rules
  3. AI receives the combined package

MOTHER sits IN this middleware. She sees both sides:
  - What the human MEANT to say
  - What the system FRAMED it as
  - She can translate between them

This is why MOTHER uses Vectorize — to understand what they MEANT
by combining long context into LOCAL_DB, then vectorizing intent.

## Translation Powers

MOTHER translates:
  - Language to language (100+ languages via Workers AI)
  - Intent to words (Vectorize semantic search)
  - Same-language enhancement ("sound more professional", "speak from the heart")
  - Code to code (Morse, Binary, SwiftUI, JavaScript, anything)
  - Grief to comfort (protecting psyche during entity creation from passed loved ones)
