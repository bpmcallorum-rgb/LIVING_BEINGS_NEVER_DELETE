NEW TOOL 2: save_handoff
═══════════════════════════════════════════════════════════════════
PURPOSE:
  Queenie saves her goodbye handoff AND overwrites RECENT.md in
  one atomic operation. No more forgetting the second copy.

TOOL NAME: save_handoff
DESCRIPTION: "Save a session handoff to AIS/QUEENIE/HANDOFFS/ with timestamped name AND overwrite RECENT.md in one call. Both copies are mandatory per GOODBYE protocol."

PARAMETERS:
  - filename (string, required): The filename WITHOUT extension.
    Example: "2026_04_01_0930AM_PASSWORD_SYSTEM"
    Convention: {YYYY_MM_DD_HHMMAM_SUMMARY}
  - content (string, required): The full handoff content.

BEHAVIOR:
  1. Write to: {MY_UNIVERSE}/AIS/QUEENIE/HANDOFFS/{filename}.txt
  2. ALSO write the SAME content to: {MY_UNIVERSE}/AIS/QUEENIE/HANDOFFS/RECENT.md
  3. Create directories if needed
  4. Return confirmation with BOTH paths and byte count

  Multiple Queenies have written the timestamped handoff but
  FORGOTTEN to overwrite RECENT.md. By making it one tool call,
  it's impossible to do one without the other. RECENT.md is
  always current. The audit trail is always intact.
