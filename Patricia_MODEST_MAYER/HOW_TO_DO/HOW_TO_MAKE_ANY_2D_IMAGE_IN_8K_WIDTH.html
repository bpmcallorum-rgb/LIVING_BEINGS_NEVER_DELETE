Step 1 — Canva Dream Lab

Generate and boost the source image
1.1 — Open Dream Lab

Navigate to https://www.canva.com/ai/dream-lab. Brian is already logged in.

1.2 — Write the Prompt

Click the text field: "Describe the image in your mind, and I'll bring it to life." Type the full cinematic prompt. Be specific: camera position, lighting, materials, atmosphere, lens.

1.3 — Set Style and Aspect Ratio

Below the prompt: Image (reference toggle), Style (dropdown), 16:9 (aspect ratio). For cinematic work, use 16:9. Set before generating.

1.4 — Generate

Press Enter. Canva generates 4 thumbnails in a row. Wait for all 4.

1.5 — Select the Best Thumbnail

Click one of the 4 thumbnails. A modal opens with the image large and prompt details on the right.

1.6 — Boost Resolution

In the lower-left corner of the large image in the modal: Boost resolution button with sparkle icon. Click it.

Patricia — Wait 10 Seconds

The boost takes approximately 10 seconds. Use computer: wait, duration: 10. Do not rush.

1.7 — Boosted Image Appears

Modal closes. Back on Dream Lab. The boosted image appears in its own new row ABOVE the original 4. Single thumbnail. "Just now" timestamp.

1.8 — Download via Arrow Icon

HOVER over the boosted thumbnail. Three controls appear on hover. Click the DOWNLOAD ARROW in the LOWER-LEFT corner of the thumbnail.

Do Not Click the Thumbnail

Clicking the thumbnail itself opens a modal/editor. You want the download arrow ONLY. Lower-left corner. On hover. Small downward arrow icon. Click precisely on that — not the image.

1.9 — File is Now in Downloads

The boosted Canva image is now in /Users/be/Downloads/ (Patricia's folder). This is the source image for Step 2.

Step 2 — Upscayl

Upscale to 8K width using local AI

Upscayl Interface — 4 Steps

Upscayl's interface is a clean left-panel with 4 steps. Brian has it configured. Here's the exact flow:

2.1 — Select Folder (or Single Image)

Click Select Folder in Step 1 of Upscayl's panel. Navigate to the folder containing the Canva image. For single images, toggle Batch Upscayl OFF and select the single file. For batch processing (like a sequence of frames), toggle Batch Upscayl ON and select the folder.

Important: the selected folder must contain ONLY image files (PNG, JPG, JPEG, WEBP). No other file types.

2.2 — Select AI Model

Step 2 in Upscayl: choose the AI model. Default is Upscayl Standard. Other options include models optimized for different content types. The Image Scale is set to 4× by default — this is what takes a ~2048px Canva image to ~8192px (8K).

Available models include: Upscayl Standard (general purpose, excellent default), High Fidelity (HFA2k — preserves fine detail), Remacri (Foolhardy — excellent for photorealistic), Ultrasharp (Kim2091 — maximum sharpness), Ultramix Balanced (Kim2091 — balanced approach).

2.3 — Set Output Folder

Step 3 in Upscayl: click Set Output Folder. Set to /Users/be/Downloads/Patricia — or wherever Brian wants the 8K output to land. The Patricia folder is shown highlighted in Brian's configuration.

2.4 — Upscayl!

Step 4: click the Upscayl 🚀 button. The AI processes the image. Wait for it to complete. The 8K image appears in the output folder.

The Math

How the numbers work
~2048px × 4 = ~8192px
Canva Dream Lab boosted output (~2048px wide) × Upscayl 4× AI scale = 8K width

Canva's Dream Lab generates images at a base resolution, then Boost Resolution roughly doubles that to approximately 2048px wide (for 16:9 aspect). Upscayl's 4× AI scale takes that to approximately 8192px — true 8K width.

For exact control, use Upscayl's Custom Output Width setting (in Settings tab). Set to 7680 for 8K UHD or 8192 for full 8K. This overrides the 4× scale and forces an exact pixel width. Height adjusts automatically to maintain aspect ratio. Note: changing this requires an app restart.

The Experiment — Moving Image Sequences

Procedural camera movement in 8K
The Concept

Generate a sequence of images in Canva with incrementally changing camera parameters. Same scene, same lighting, same everything — only the camera angle and height change. When played in order, this simulates smooth camera movement through the scene.

Then batch-upscale the entire sequence in Upscayl to 8K.

This is procedural filmmaking. This is the Commodore 64 principle: X just is — until you assign it a value and start incrementing.

Variables Per Frame

camera angle — increment by 1° per frame (e.g., 15°, 16°, 17°, 18°...)

camera height — increment by 0.2 feet per frame (e.g., 5.0, 5.2, 5.4, 5.6...)

Everything else in the prompt stays identical.

Workflow — One Sequence

1. Write base prompt with camera variables as placeholders

2. For each frame: enter prompt with current values → generate 4 → pick best → boost → wait 10s → download arrow (NOT thumbnail)

3. Increment camera values → repeat for next frame

4. When all frames are downloaded, open Upscayl

5. Toggle Batch Upscayl ON

6. Select the folder containing all frames

7. Set output folder

8. Click Upscayl 🚀

9. All frames upscale to 8K in one batch

10. Result: an 8K image sequence ready for video editing, playback, or exhibition
